# Big Data Pipeline & Power BI Analytics

## Présentation
Ce projet est axé sur la chaîne de traitement complète de données massives, de l'ingestion jusqu'à la restitution décisionnelle. La solution permet d'absorber de grands volumes de données provenant de sources hétérogènes et de fournir des indicateurs de performance clés en temps réel.

## Fonctionnalités Principales
- **Ingestion & Processus ETL :** Automation de l'extraction, de la transformation et du chargement des données multi-sources.
- **Modélisation SQL :** Optimisation du schéma de base de données et des requêtes lourdes (jointures, agrégations) pour garantir des temps de réponse rapides.
- **Visualisation Power BI :** Conception de tableaux de bord interactifs pour l'analyse des métriques et le reporting décisionnel.

## Stack Technique
- **Traitement & Modélisation :** SQL, Python (Pandas)
- **Analytics & BI :** Power BI
- **Outillage :** Git, ETL Studio
